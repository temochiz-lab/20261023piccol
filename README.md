# Piccol

画像から好きな範囲を切り抜き、元画像の上に配置して調整できるブラウザーアプリです。

## 使い方

`index.html` をブラウザーで開きます。左パネルから画像を選ぶか貼り付けるか、編集エリアにドラッグ＆ドロップします。四角または円を選んで画像上をドラッグすると切り抜き範囲を指定できます。範囲の中をドラッグすると範囲を移動でき、四隅のハンドルをドラッグするとサイズを調整できます。左パネルから画像の表示倍率も変更できます。

選択範囲をPNGとして保存・コピーします。円のPNGは円の外側が透明になります。クリップボードへのコピーには Clipboard API が使える HTTPS または localhost の環境が必要です。
