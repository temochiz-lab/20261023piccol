# Piccol

画像から好きな範囲を切り抜き、元画像の上に配置して調整できるブラウザーアプリです。

## 使い方

`index.html` をブラウザーで開きます。画像ファイルを選ぶか、編集エリアにドラッグ＆ドロップするか、画像をコピーして貼り付けます。画像の表示倍率を調整し、四角または円を選んで画像上をドラッグすると切り抜き範囲を指定できます。「切り抜きを配置」を押すと元画像上に重なります。ドラッグで移動、右下のハンドルで縦横比を保ったまま拡大縮小できます。

配置前は選択範囲をPNGとして保存・コピーし、配置後は元画像に切り抜きを重ねた画像全体をPNGとして保存・コピーします。円のPNGは円の外側が透明になります。クリップボードへのコピーには Clipboard API が使える HTTPS または localhost の環境が必要です。
